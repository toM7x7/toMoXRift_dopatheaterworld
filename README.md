# ドパガキシネマ（試作）

画面共有した映像の色が、スクリーンの外へにじみ出して部屋じゅうを染める映画館。
ブラウザー拡張「Ambient light for YouTube™」の光を 3D の部屋に広げたもの。

## しくみ

- 映像は公式の `ScreenShareContext` の `videoElement` から自分で `VideoTexture` を作って読む（`src/CinemaScreen.tsx`）。スクリーンと光の計算で同じテクスチャを共有するので、映像の転送は1回で済む。
- `src/ambient/engine.ts` が毎秒最大30回、映像を 256×144 に縮め、そこから 128×72（軽くぼかす＝形が分かる）と 64×36（大きくぼかす）を作り、それぞれ前の結果と混ぜてなめらかにする。部屋の材質はこの2枚を読む。
- 色はレンダラーの ACES を使わず、色相を保つ自前のトーンカーブ（`ambTone`）で出す。明るい色が白っぽく抜けず、拡張機能のように鮮やかに残る。
- 通信は増やさない。各自の端末に届いた同じ映像から各自で計算する。

| 演出 | 場所 | 中身 |
|---|---|---|
| 後光 | `Halo`（Effects.tsx） | 縁のすぐ外は軽くぼかした映像をわずかに拡大（形が縁の外へ続く）、外側は大きく拡大して強くぼかした映像。2層を混ぜてゆっくり薄くする |
| 映像を部屋に広げる | `USE_PROJECT`（materials.ts） | 客席の中央から見た延長線でスクリーン面を無限に広げ、壁・天井・床にその位置の映像を映す。近くは拡大した映像、遠くは縁の色になり、左の壁には左端、天井には上端が続く |
| 部屋が染まる | `createRoomMaterial`（materials.ts） | スクリーンを 6×4 の光る板とみなし、壁・床・天井・座席の頂点ごとに受ける光を計算。光の減り方は 1/d² でなく ≈1/d に誇張 |
| 角への回り込み | `haloWrap` | 後光が隣の壁・天井・床にも落ちる |
| 床の映り込み | `USE_REFLECT` | 視線を床で反射してスクリーン面に当て、映像と後光を拾う。スクリーン前は磨いた舞台、客席はじゅうたん |
| 映写の光の筋 | `ProjectorBeam` | 四角錐の裏面で、視線が光の中を通る長さを計算して明るさにする |
| ほこり | `BeamDust` | 待機中だけ客電の光で部屋に漂う。映像が始まると消える（視聴の邪魔にならないように） |
| アバターを照らす | `AudienceLights` | 映像の左半分・右半分の平均色を4画素だけ読み出し、左右のスポットライトの色にする |
| 客電 | `uHouse` | 映像が出ると部屋の明かりが落ちる |

映写機に触れると、自分の見え方だけ光の強さが 標準 → 強 → 弱 → 切 と変わる（同期しない）。

### 上映中は部屋が消える（v5〜）

映像の中身では決めず、画面共有があるかどうかだけで決める（`engine.ts` の `show`）。読み込みのぐるぐる、止まりかけたライブ配信、動かないゲーム画面でも部屋がちらつかない。v4 の「盛り上がり度」で消す方式はこのためにやめた。

| できごと | 部屋 |
|---|---|
| 共有前 | 映画館のまま |
| 映像が届く | 光が広がり、2秒後（`IMMERSE_DELAY`）にスクリーン側から崩れ始め、5秒（`IMMERSE_IN`）で客席の奥まで消える |
| 上映中（止まる・読み込み・一時停止・暗い場面） | 消えたまま。光は映像どおりに変わるだけ（止まれば最後の色で止まる） |
| 共有が 3秒（`SHARE_GRACE`）以内に戻る（つなぎ直し・別の人への切り替え） | 消えたまま。途切れている間は光を最後の色のまま保ち、スクリーンは黒（共有の案内は出さない） |
| 共有が止まって 3秒たつ | 客電がつき、後ろの席から組み上がって 3秒（`IMMERSE_OUT`）で戻る |

- 消えるもの：黒枠・カーテン・柱・パネル・梁・照明・非常口・座席・肘掛け（光る縁を伴って崩れる）。消えても座る判定（見えない箱）は残る。
- 残るもの：壁・天井・床の素地（`AC_*_base`・舞台・じゅうたん。映像の続きを映す面になる）・スクリーン・映写機（光の強さのスイッチなので上映中も見つけられるように。客席の後ろなので映像の邪魔にならない）。
- 共有の有無は `videoElement` があることに加え、映像のトラックが終わっていないこと（`readyState !== 'ended'`）で見る。止まりかけた配信はトラックが生きているので「共有中」のまま。
- 光を「切」にしている人の部屋は消えない（上映中に切にすると 3秒で戻る）。
- 開発パネルの「固める（止まりかけ）」「一瞬切る 1.5秒」「切る 6秒」と、状態の表示で試せる。時間の流れの確認は `node scripts/check-show.mjs`（GPU の Chrome で状態を記録し、`docs/screenshots/show-*.png` を撮る）。

## 部屋の作り（v3〜）

- 設計書 `design/index.html`：部屋を P1 スクリーンまわり／P2 横の壁／P3 天井／P4 床／P5 座席／P6 後ろに分け、部位ごとに画像生成の案（`design/concepts/`）と寸法つき設計図（`design/blueprints/`）をそろえた。
- 寸法の正本は `design/layout.json`（ワールドの `src/layout.ts` も読む）と `blender/cinema_spec.py`（部位の細部）。設計図は `python blender/blueprints.py`、PNG は `node scripts/render-svgs.mjs`。
- Blender 正本は `blender/build_cinema.py`（Blender MCP で exec）。別シーン `ambient_cinema` に組み、素材ごとに1メッシュにまとめて `public/ambient-cinema.glb` へ書き出す。確認用に `blender/ambient_cinema.blend` も保存。
- ワールドは GLB の素材名（`AC_*`）で映像の光のシェーダーに差し替える（`src/Room.tsx` の `SURFACES` / `GLOWS`）。ベルベットの縁の光、じゅうたんの柄、真鍮の映り込みはシェーダー側。
- 座席は1脚・肘掛け1本・端の板だけを GLB に入れ、ワールドでインスタンス描画（1素材1回）。80席すべて `<Seat>` で座れる（座る判定は座面の上の見えない箱）。
- 当たり判定はコードの箱（床・斜面・台・壁・映写機の台）。座席・カーテン・柱は通り抜けられる。
- 手元の計測（GPU の Chrome）：描画 30回／フレーム、約 12.4 万三角形、60fps。Quest は未計測。

## 開発

```bash
npm run dev   # http://127.0.0.1:5290
```

スクリーンをクリックするとテスト映像が流れる。右上のパネルで動画ファイルも選べ、各値を調整できる。
URL の指定は `src/dev.tsx` の先頭に書いてある（`?play=1&scene=2` など）。

開発用のコードも dist に入るので、`navigator.mediaDevices`（公式検査で禁止）は使わず、テスト映像は canvas の `captureStream` で作っている。

## 外部レビュー（2026-11-07）

- **コード**：Codex CLI（codex-cli 0.162.1）に本番のソースを行番号つきで渡して読ませた（11件、高はなし）。直したもの：
  - 映像トラックが終わったのに要素が残る場合も、スクリーンを黒にして共有終了と同じ流れにする（`CinemaScreen.tsx`）。映像トラックが無いストリームは「共有なし」と扱う（`engine.ts` の `sourceAlive`）。
  - 共有の待ち時間は実時間で数える（タブを隠していた間も進む）。描画のなめらかさ用の dt とは分けた。
  - 縮小・ぼかしの描画は try/finally で囲み、ホストの描画設定を必ず戻す。光が「切」の間は縮小・ぼかしを止め、光の筋も描かない。
  - `AmbientEngine` のマテリアルと板の解放漏れ、StrictMode で素材の後片付けが漏れる点（`Room.tsx`）、GLSL で未定義の逆順 `smoothstep` 2か所。
- 直さなかったもの（理由つき）：
  - 映像の sRGB を線形に戻さずに光を計算している点は事実（three は動画を線形の RGBA8 で上げ、標準素材だけがシェーダーで変換する）。今の見た目はこの前提で調整済みで、開発と本番で同じ動きなので変えていない。変えると部屋の中間調が暗く、色が濃くなる。
  - 光の筋の四角錐にスクリーン側の底面が無い点は意図どおり（付けると映像の上に霞がかかる）。
  - 上映中に「切」にすると部屋が3秒かけて戻る点は、演出として残した。
- **日本語**：Antigravity CLI（agy 1.4.12、Gemini 4 Argon High）で、説明文・画面の文言・サムネイルの文字・README を校正。説明文の「クリックして」→「選んで」、主語の補い、映写機の場所、画面の「光の演出」→「光の強さ」、待機画面の文末、README の表記ゆれを直した。
